# Capture Pro 2.0.0 — instalador único (Windows 10/11, 64 bits)

1. Baixe **somente** `CapturePro-Setup-2.0.0.exe`.
2. Execute e avance as telas. Todos os componentes já estão dentro do arquivo.
3. Se aparecer "O Windows protegeu o computador", clique em *Mais informações → Executar assim mesmo*.

**Já tem a 1.0?** Basta instalar por cima. Imagens, pasta de destino, prefixo, última placa,
ajustes e áreas salvas são mantidos. Uma cópia de segurança das configurações é criada em
`%APPDATA%\CapturePro\config.backup-antes-v2.0.0.json`.

Para conferir o download, compare com `SHA256SUMS.txt`.
