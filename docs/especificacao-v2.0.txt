Antes de qualquer alteração:

ETAPA 2 — PRIMEIRA ALTERAÇÃO: MENU DE SELEÇÃO DE ÁREA

ESTA É A PRINCIPAL MODIFICAÇÃO DO PROJETO.

Atualmente existe um botão na parte inferior chamado:

DEFINIR ÁREA

Esse botão já funciona perfeitamente.

Ao clicar, aparece a moldura sobre a imagem, permitindo arrastar, mover e redimensionar o retângulo.

O funcionamento atual está aprovado.

NÃO ALTERAR:

- O botão DEFINIR ÁREA.
- Seu tamanho.
- Sua posição.
- Seu formato.
- Sua cor.
- Sua ação original.
- O comportamento de abertura da seleção.
- A aparência da moldura.
- A cor e o estilo das linhas.
- Os pontos de redimensionamento.
- A movimentação com o mouse.
- O cálculo do recorte.
- A prévia ao vivo.
- A forma como a imagem é salva.

O QUE DEVE SER ACRESCENTADO

Quando o usuário clicar no botão existente DEFINIR ÁREA, o sistema continuará entrando no modo de seleção exatamente como já acontece.

A única novidade será apresentar duas pequenas opções contextuais:

SALVAR ÁREA

REMOVER SELEÇÃO

Essas opções devem aparecer exclusivamente enquanto o usuário estiver no modo de definição de área.

Não criar uma nova janela grande.

Não abrir outra tela.

Não modificar o botão original.

Não adicionar barras permanentes à interface.

Utilizar dois pequenos botões discretos, preferencialmente na mesma região inferior onde já aparecem os controles da seleção.

FUNCIONAMENTO DA OPÇÃO SALVAR ÁREA

Quando o usuário clicar em SALVAR ÁREA:

1. Confirmar o retângulo que ele acabou de selecionar.
2. Gravar suas coordenadas usando o mecanismo de persistência já existente.
3. Encerrar o modo de edição.
4. Ocultar as duas opções contextuais.
5. Retornar à interface normal.
6. Manter a área selecionada visualmente marcada, exatamente como já acontece.
7. Continuar capturando somente o interior da área escolhida.

A área deverá permanecer gravada mesmo depois de fechar e abrir o programa.

IMPORTANTE: o botão SALVAR ÁREA deverá reutilizar a ação já existente do botão CONCLUIR ÁREA. Não criar outro sistema de salvamento de coordenadas.

FUNCIONAMENTO DA OPÇÃO REMOVER SELEÇÃO

Quando o usuário clicar em REMOVER SELEÇÃO:

1. Excluir a área de recorte atualmente definida para o dispositivo.
2. Remover a moldura da prévia.
3. Voltar automaticamente ao modo de captura integral do quadro.
4. Encerrar o modo de edição.
5. Ocultar as duas opções contextuais.
6. Retornar à interface normal.
7. Persistir a remoção para que a seleção antiga não reapareça ao reiniciar.

IMPORTANTE: reutilizar a lógica já existente do botão CAPTURAR TELA INTEIRA, sem reimplementar o mecanismo de captura.

COMPORTAMENTO VISUAL OBRIGATÓRIO

Estado normal:

O programa permanece visualmente igual à versão 1.0. As duas opções adicionais ficam ocultas.

Ao clicar em DEFINIR ÁREA:

A seleção abre exatamente como hoje, com a mesma moldura e os mesmos controles de movimentação e redimensionamento.

Somente nesse momento aparecem:

- SALVAR ÁREA
- REMOVER SELEÇÃO

Ao clicar em qualquer uma dessas opções, elas desaparecem e o programa volta à aparência normal.

Não alterar a disposição dos outros botões.

Não mudar o tamanho da janela.

Não alterar a área de visualização.

Não alterar o painel lateral.

Não substituir os controles existentes por novos componentes.

Se houver um botão CONCLUIR ÁREA durante a edição, adaptar apenas esse controle contextual para SALVAR ÁREA e acrescentar REMOVER SELEÇÃO ao lado, sem alterar os demais controles.

O botão CAPTURAR TELA INTEIRA já existente deverá continuar funcionando como antes. Não o remover.

ATENÇÃO

A seleção de área está perfeita na versão 1.0.

Não tente melhorá-la.

Não altere seu algoritmo.

Não altere a renderização.

Não modifique as coordenadas.

Não mexa nas linhas ou nas alças.

A alteração solicitada é somente a inclusão das duas ações contextuais, aproveitando as funções que já existem.

ETAPA 4 — TERCEIRA ALTERAÇÃO: INSTALADOR ÚNICO

A versão 1.0 foi distribuída em duas partes:

- CapturePro-Setup-1.0.0.exe
- CapturePro-Setup-1.0.0-parte2.exe

Quero eliminar essa necessidade na versão 2.0.

NOVO FORMATO

Gerar um único arquivo:

CapturePro-Setup-2.0.0.exe

Esse instalador deverá conter todos os componentes necessários ao funcionamento do programa, incluindo:

- Executável principal.
- Python embutido.
- Bibliotecas PySide6/Qt.
- OpenCV.
- Dependências DirectShow/Media Foundation utilizadas pelo aplicativo.
- Bibliotecas auxiliares.
- Recursos visuais.
- Ícones.
- Demais arquivos necessários.

O usuário deverá baixar somente um arquivo, executar e instalar.

Não poderá ser necessário baixar uma segunda parte.

Não poderá ser necessário instalar Python separadamente.

Não poderá ser necessário baixar bibliotecas durante a instalação.

Não poderá ser necessário instalar ferramentas de desenvolvimento.

Preservar o sistema de instalação NSIS já existente, adaptando-o para gerar um instalador monolítico.

Se o limite de tamanho do ambiente de desenvolvimento ou da plataforma de distribuição impedir o envio de um arquivo único, procurar uma estratégia apropriada de publicação, como GitHub Releases, sem dividir o instalador para o usuário final.

Não reduzir a funcionalidade do programa para diminuir o tamanho do instalador.

Não remover dependências necessárias.

INSTALAÇÃO E ATUALIZAÇÃO

O instalador 2.0 deverá:

1. Instalar todos os componentes.
2. Criar os atalhos necessários.
3. Permitir desinstalação.
4. Preservar imagens já capturadas.
5. Preservar configurações existentes da versão 1.0.
6. Preservar a última placa utilizada.
7. Preservar os recortes já salvos.
8. Atualizar a instalação anterior de forma segura.

Manter compatibilidade com o arquivo de configurações já existente.

Não apagar configurações antigas durante a atualização.

Se for necessária qualquer migração, criar backup e validar os dados antes de gravar o novo formato.
